## Project Overview

Aum Tatva is an e-commerce website offering Rudraksha, Shaligram, gemstones, malas, spiritual accessories and related services.

My development work focuses on creating a modern shopping experience through advanced WooCommerce customization, custom user interfaces, product management, third-party integrations and performance improvements.
